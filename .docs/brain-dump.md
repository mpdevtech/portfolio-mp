# Projeto: Meu Portfólio

### Ideia inicial: 

- Gerei um promtp no chat GPT para ser usado no figma para a criação de um site. A ideia é criar uma página de portfólio dos meus trabalhos como designer gráfico. Pedi para me sugerir como pedir da melhor forma para o figma. Solicitei que queria um site que tivesse uma tela inicial com headline a esquerda com um botão "entre em contato" abaixo  e minha foto a direita.

- A seção seguinte é "Meus trabalhos" com 6 cards sendo 3 abaixo um do outro com.

- A próxima seção é "Sobre mim" com uma foto minha a esquerda e um título e texto curto a direita.
- A última seção é para contatos (WhatsApp, Instagram, Email). Anexei imagens de referência visual, além de minhas fotos para serem usadas no projeto.

- A paleta de cores usada para o site é Preto não 100% e Laranja com um leve toque de azul escuto em alguns detalhes.

- Ao clicar em um dos cards dos trabalhos, ver a melhore opção entre abrir um slide com mais fotos ou uma nova página com o projeto completo.

### Promp gerado pelo ChatGPT para ser usando no Figma:

"Crie o layout de um site de portfólio profissional para um designer gráfico, com foco em apresentar meus principais trabalhos, reforçar minha identidade profissional e facilitar o contato com potenciais clientes.
Quero um site visualmente sofisticado, contemporâneo, minimalista e autoral, com forte cuidado tipográfico, boa hierarquia visual e bastante respiro entre os elementos. O design deve transmitir criatividade, personalidade e profissionalismo, sem parecer excessivamente corporativo ou genérico.
Use as imagens de referência anexadas como inspiração visual, principalmente para composição, tipografia, espaçamentos, tratamento das imagens, proporções e linguagem visual. Não copie literalmente os layouts das referências; crie uma composição original seguindo a mesma direção estética.
Use também minhas fotografias anexadas nas áreas indicadas abaixo. Não substitua minhas fotos por imagens genéricas.
Crie inicialmente a versão desktop com 1440 px de largura, utilizando grid consistente, Auto Layout sempre que possível, componentes reutilizáveis e uma estrutura organizada de camadas. Estruture o projeto pensando também em futura adaptação responsiva para tablet e mobile.
1. Header
Crie um header simples, elegante e discreto.
À esquerda:
- meu nome ou logotipo.
À direita:
- Trabalhos
- Sobre
- Contato
O header deve combinar com o restante do site, sem ocupar espaço visual excessivo.
Pode ser fixo ou permanecer no topo de forma simples, desde que mantenha uma boa experiência de navegação.
2. Hero / Tela inicial
Crie uma primeira seção de grande impacto visual, ocupando boa parte da altura da tela.
À esquerda:
- pequena identificação como “Designer Gráfico”;
- uma headline grande, marcante e com bastante personalidade;
- um pequeno texto complementar, se necessário;
- botão principal com o texto “Entre em contato”.
A headline pode seguir uma direção semelhante a:
“Design que transforma ideias em marcas memoráveis.”
À direita:
- utilize minha foto anexada como elemento principal;
- dê bastante destaque à fotografia;
- pode utilizar recorte, máscara, composição assimétrica, sobreposição ou outro recurso contemporâneo;
- evite simplesmente colocar a foto dentro de um retângulo comum;
- faça com que a fotografia faça parte da composição visual.
O Hero deve causar uma primeira impressão forte, criativa e sofisticada, mantendo o visual limpo.
3. Meus Trabalhos
Crie uma seção chamada:
“Meus trabalhos”
Inclua uma pequena frase introdutória sobre projetos de identidade visual, design gráfico, campanhas, comunicação visual ou projetos digitais.
Apresente 6 projetos em cards, organizados em:
3 colunas × 2 linhas no desktop.
Cada card deve conter:
- imagem principal do projeto em bastante destaque;
- nome do projeto;
- categoria;
- indicação discreta de “Ver projeto”.
Priorize as imagens. Evite cards excessivamente pequenos ou cheios de informações.
Utilize imagens anexadas dos meus projetos quando disponíveis. Para projetos sem imagem fornecida, utilize placeholders discretos que possam ser facilmente substituídos depois.
Adicione interações visuais que possam ser usadas futuramente em hover, como:
- leve zoom da imagem;
- mudança de contraste;
- aparecimento de “Ver projeto”;
- pequeno movimento ou transição suave.
A interação deve ser elegante e discreta.
4. Comportamento ao clicar em um projeto
Ao clicar em um dos cards de Meus Trabalhos, o usuário deve acessar uma página individual dedicada ao projeto.
Não utilize apenas um modal simples ou um slider sobre a Home.
A melhor experiência deve ser uma página completa de case, onde o projeto possa ser apresentado com mais profundidade.
Crie também o conceito visual dessa página.
Página individual do projeto
Crie um template reutilizável de página de projeto, para que todos os trabalhos possam seguir a mesma estrutura visual.
A página deve conter:
- botão ou link de “Voltar aos trabalhos”;
- nome do projeto;
- categoria;
- ano, quando aplicável;
- breve descrição do projeto;
- imagem principal em grande destaque;
- galeria com várias imagens;
- mockups;
- aplicações da identidade;
- detalhes visuais;
- possibilidade de utilizar slider ou carrossel dentro da página;
- imagens em diferentes proporções;
- blocos visuais grandes;
- navegação entre Projeto anterior e Próximo projeto no final.
A página deve funcionar como um case visual de portfólio, valorizando principalmente as imagens e evitando excesso de texto.
A estrutura pode seguir uma lógica semelhante a:
Título → Informações → Imagem principal → Galeria → Slider → Aplicações → Próximo projeto
Mantenha a mesma identidade visual da página principal.
Crie esse template de forma que novos projetos possam ser adicionados posteriormente sem precisar redesenhar toda a estrutura.
5. Sobre mim
Crie uma seção chamada:
“Sobre mim”
Use um layout dividido em duas partes.
À esquerda:
- utilize outra fotografia minha anexada;
- a imagem pode ocupar aproximadamente 40% a 45% da largura da seção.
À direita:
- título “Sobre mim”;
- headline curta;
- pequeno texto de apresentação.
Utilize inicialmente um texto semelhante a:
“Sou designer gráfico e trabalho transformando ideias em soluções visuais que comunicam com clareza, personalidade e propósito. Minha experiência envolve identidade visual, comunicação de marca e criação de experiências digitais.”
Não crie uma seção excessivamente longa.
A seção deve ser pessoal, profissional e visualmente integrada ao restante do site.
6. Contato
Finalize o site com uma seção forte de contato.
Utilize uma chamada como:
“Vamos criar algo juntos?”
Inclua os canais:
- WhatsApp
- Instagram
- E-mail
Esses contatos podem aparecer como:
- links grandes;
- botões;
- elementos tipográficos;
- ícones discretos.
Mantenha a mesma identidade visual do restante do site.
Inclua também um rodapé simples com:
Marcos Paulo — Designer Gráfico
e espaço para copyright.
Direção visual
Quero uma estética:
- moderna;
- sofisticada;
- criativa;
- minimalista;
- editorial;
- autoral;
- com tipografia de grande impacto;
- bastante espaço negativo;
- grid consistente;
- contraste claro entre títulos e textos;
- imagens grandes;
- poucos elementos puramente decorativos.
Evite aparência de template genérico de agência ou portfólio pré-pronto.
Busque uma composição que pareça um portfólio autoral de designer, valorizando principalmente meus trabalhos, minha personalidade e meu estilo visual.
Paleta de cores
Utilize a seguinte direção cromática:
Cor principal
Preto não 100%
Use um preto suave, carvão ou grafite escuro como base visual.
Evite preto absoluto puro em toda a interface.
Exemplos de direção:
- #111111
- #141414
- #171717
- #1A1A1A
Não é obrigatório utilizar exatamente esses códigos; use-os apenas como referência de tonalidade.
Cor de destaque principal
Laranja
O laranja deve ser a principal cor de destaque do site.
Pode aparecer em:
- botões;
- links;
- pequenos elementos de interface;
- hover;
- indicadores;
- palavras em destaque;
- detalhes gráficos;
- pequenos elementos decorativos.
O laranja deve trazer energia e personalidade sem dominar excessivamente a interface.
Cor de apoio
Azul escuro
Utilize azul escuro apenas em pequenos detalhes.
Pode aparecer em:
- divisores;
- tags;
- pequenos elementos gráficos;
- estados de hover;
- sombras sutis;
- detalhes de fundo;
- pequenos acentos visuais.
O azul escuro deve funcionar apenas como apoio e não competir com o laranja.
A predominância deve ser:
Preto suave → Laranja → pequenos detalhes em azul escuro.
Tipografia
Utilize uma tipografia contemporânea e sofisticada.
Para títulos:
- fonte de forte personalidade;
- boa presença visual;
- adequada para grandes tamanhos.
Para textos:
- fonte limpa;
- alta legibilidade;
- visual moderno.
Pode utilizar uma combinação de:
- uma fonte mais expressiva nos títulos;
- uma fonte neutra nos textos.
Evite fontes excessivamente futuristas ou difíceis de ler.
Grid e espaçamentos
Utilize:
- grid consistente;
- margens generosas;
- espaçamentos bem definidos;
- bastante respiro entre seções.
Evite layouts apertados.
A página deve transmitir uma sensação de:
- organização;
- clareza;
- sofisticação;
- controle visual.
Responsividade
Mesmo que o layout inicial seja criado em desktop de 1440 px, pense desde o início em uma adaptação futura para:
- desktop;
- tablet;
- mobile.
Evite soluções que dependam de posicionamentos impossíveis de adaptar.
Estruture os elementos utilizando Auto Layout sempre que possível.
Organização para futura implementação
Prepare o layout para futura implementação em:
- HTML;
- CSS;
- JavaScript;
- React.
Evite posicionamentos desnecessariamente complexos.
Utilize:
- Auto Layout;
- componentes;
- estilos reutilizáveis;
- espaçamentos consistentes;
- estrutura organizada de camadas;
- nomes claros para frames e componentes.
Crie o projeto de forma que possa ser interpretado posteriormente através do Figma MCP e implementado por uma IA de desenvolvimento como o Codex no VS Code.

Header → Hero → Meus Trabalhos → Sobre mim → Contato → Footer

Template individual de Projeto
